# writer-pi
A writing agent built on Pi for drafting, editing, and preserving your voice.

Based on the Pi Agent Harness (upstream: https://github.com/earendil-works/pi, merged from badlogic/pi-mono upstream).

## Upstream packages (vendored via git merge)

* **[@earendil-works/pi-coding-agent](packages/coding-agent)**: Interactive coding agent CLI
* **[@earendil-works/pi-agent-core](packages/agent)**: Agent runtime with tool calling and state management
* **[@earendil-works/pi-ai](packages/ai)**: Unified multi-provider LLM API (OpenAI, Anthropic, Google, …)

See the full upstream README below.
