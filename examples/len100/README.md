# len100 示例：短长度目标（100 字左右）

100 字档示例：咖啡馆短评，验证 100 字量级下带禁用词的 brief 约束。

在这个目录启动 writer-pi：

```bash
cd examples/len100
writer-pi
```

然后在交互界面输入：

```
/draft 写一篇巷口咖啡馆的短评
```

brief.md 写好口径（长度、语气、禁用词），sources/facts.md 是需要处理的事实。article.md 是一次真实运行得到的最终稿。

实测字数（口径：中文字符 + 英文单词 + 数字组）：83 字，目标 100 字（±20% 达标线 80–120，达标）。
