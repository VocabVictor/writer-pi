# len250 示例：短长度目标（250 字左右）

250 字档示例：书店推荐语，验证 250 字目标的约束。

在这个目录启动 writer-pi：

```bash
cd examples/len250
writer-pi
```

然后在交互界面输入：

```
/draft 写一段《词语的航海》的推荐语
```

brief.md 写好口径（长度、语气），sources/facts.md 是需要处理的事实。article.md 是一次真实运行得到的最终稿。

实测字数（口径：中文字符 + 英文单词 + 数字组）：206 字，目标 250 字（±20% 达标线 200–300，达标）。
