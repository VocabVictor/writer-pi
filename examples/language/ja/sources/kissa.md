# 駅前の喫茶店(扱う素材)

- 店名:純喫茶つばき。駅の西口から歩いて三分、昭和四十一年の創業。
- マスターは三人目で、創業者の息子ではなく、四十年前に住み込みで働いていた人。
- メニューはホットコーヒー(四百円)とトーストとクリームソーダしかない。
- コーヒーはサイフォンで淹れる。一杯ずつ、注文を受けてから火にかける。
- 店内の椅子は丸い一人掛けで、座面の革にヒビが入っている。
- 午後二時から三時はマスターが昼食をとるため仕切りを下ろす。
- 常連の老人が毎朝七時に来て、同じ窓際の席で新聞を折り目どおりに畳む。
- 支払いは現金のみ。レジは押しボタン式の旧型で、引き出しが閉まるとき音がする。
