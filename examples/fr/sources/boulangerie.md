# La boulangerie du coin (matière à traiter)

- Nom : Boulangerie Laurent, rue des Lilas, ouverte en 1958.
- Le boulanger actuel, M. Laurent, est le petit-fils du fondateur ; il faut quatre heures de travail avant l'ouverture du four.
- Le pain de campagne est cuit deux fois par jour, à six heures et à quinze heures.
- La file du samedi matin déborde sur le trottoir ; personne ne se sert, M. Laurent appelle les clients un par un.
- La vitrine du fond garde les pièces montées des week-ends, souvent invendues et données à l'école voisine le lundi.
- Le fournil est derrière un rideau en toile ; on y entend taper le pétrin avant l'aube.
- Fermé le lundi. Le mardi, le premier client entre à six heures dix.
- La caisse est une vieille machine à manivelle ; M. Laurent note ses ventes dans un cahier d'écolier.
