# 示例：科普文（高山上为什么煮不熟饭）

在这个目录启动 writer-pi：

```bash
cd examples/popsci
writer-pi
```

然后在交互界面输入：

```
/draft 写一篇高山上为什么煮不熟饭的科普文 --genre=popsci
```

brief.md 已声明体裁 `popsci`（科普文），sources/physics.md 是气压、沸点与权威说法等
事实。流程会自动进行：定主线与类比 → 起草 → 保存初稿 → 程序检查 → 语义检查 →
（最多两轮）局部修改。体裁要求类比只解释机制不替代证据，并写清类比失效的地方；
结论强度必须与材料一致，相关性不得被写成因果。article.md 是一次真实运行得到的成品。
