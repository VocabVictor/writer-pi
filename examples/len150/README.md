# len150 示例：短长度目标（150 字左右）

150 字档示例：工作交接便条，验证逐条列事项时 150 字目标的约束。

在这个目录启动 writer-pi：

```bash
cd examples/len150
writer-pi
```

然后在交互界面输入：

```
/draft 写一张工作交接便条
```

brief.md 写好口径（长度、语气），sources/facts.md 是需要处理的事实。article.md 是一次真实运行得到的最终稿。

实测字数（口径：中文字符 + 英文单词 + 数字组）：130 字，目标 150 字（±20% 达标线 120–180，达标）。
