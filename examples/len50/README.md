# len50 示例：短长度目标（50 字左右）

最小长度档的示例：一句话状态便条，验证 50 字量级下 brief 的「长度：50 字左右」能否约束生成。

在这个目录启动 writer-pi：

```bash
cd examples/len50
writer-pi
```

然后在交互界面输入：

```
/draft 写一条今天到岗延迟的状态便条
```

brief.md 写好口径（长度、语气），sources/facts.md 是需要处理的事实。article.md 是一次真实运行得到的最终稿。

实测字数（口径：中文字符 + 英文单词 + 数字组）：41 字，目标 50 字（±20% 达标线 40–60，达标）。
