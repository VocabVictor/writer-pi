# Пример ru: городская зарисовка по заметкам

Запустить writer-pi в этом каталоге:

```bash
cd examples/ru
writer-pi
```

Затем ввести в интерактивном режиме:

```
/draft Напиши городскую зарисовку про старый трамвай
```

В brief.md лежат требования (целевой язык, жанр, объём, запрещённые слова); sources/tramvai.md — материал.
Неинтерактивная генерация:

```bash
node ../../packages/coding-agent/dist/bundle/cli.js -a -p "/draft Напиши городскую зарисовку про старый трамвай" --no-session
```

Процесс идёт автоматически: черновик, сохранение, проверки, правки.
Финальный текст — в article.md, версии — в drafts/.
