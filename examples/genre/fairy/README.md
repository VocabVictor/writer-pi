# 示例：童话寓言（小田鼠的三颗豆子）

在这个目录启动 writer-pi：

```bash
cd examples/genre/fairy
writer-pi
```

然后在交互界面输入：

```
/draft 写一则童话：小田鼠的三颗豆子 --genre=fairy
```

brief.md 已声明体裁 `fairy`（童话寓言），sources/synopsis.md 是故事梗概与角色设定。
童话体裁面向儿童读者：重复句式（三次反复）是修辞设计，检查按 loose 处理不报冗余；
寓意收尾是结构要求，结尾由情节自然带出寓意，不生硬说教。
article.md 是本次生成的定稿。
