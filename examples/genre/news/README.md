# 示例：新闻稿（图书馆 24 小时自习区试运行）

在这个目录启动 writer-pi：

```bash
cd examples/genre/news
writer-pi
```

然后在交互界面输入：

```
/draft 写一份江州市图书馆 24 小时自习区试运行的新闻稿 --genre=news
```

brief.md 已声明体裁 `news`（新闻稿），sources/facts.md 是 5W、数据与引语等事实素材。
流程会自动进行：定 5W 与层次 → 起草 → 保存初稿 → 程序检查 → 语义检查 →
（最多两轮）局部修改。倒金字塔结构由体裁约定：导语承载 5W，重要信息在前；
一切事实与引语必须可追溯到素材，虚构引语会被语义检查拦下。
article.md 是一次真实运行得到的成品。
