# 中文独立博客二十年调研素材

## 时间线关键节点

- 2002-2005 年：博客中国、BlogBus、MSN Spaces 先后上线，独立博客以自建（Movable Type、WordPress、Textpattern）与 BSP（博客托管服务）两条线并行。
- 2005 年：新浪博客上线，名人博客策略带动平台博客用户量暴涨；独立博客圈开始出现"平台会拿走读者"的争论。
- 2008-2009 年：饭否、Twitter 兴起，短内容分流长文读者；Google Reader 在中文技术圈是主要阅读入口。
- 2010-2011 年：独立域名备案要求收紧，部分个人站点因备案问题关停或迁移境外主机。
- 2013 年：Google Reader 关闭（7 月 1 日），RSS 阅读生态受重创，中文技术博客的订阅量普遍下降一半以上（多位博主自述数据）。
- 2013-2015 年：微信公众号兴起，长文写作向平台集中，公众号没有外链与 RSS，读者关系归平台。
- 2016-2018 年：知乎、掘金、简书等平台承接技术内容；独立博客圈缩到技术圈与摄影圈等少数领域。
- 2017 年起：Matters、Medium 中文圈尝试;部分写作者回流自建站点，静态站点生成器（Hexo、Hugo、Jekyll）降低建站成本。
- 2019-2021 年：RSS 复兴讨论再起，Feedly、Inoreader、Miniflux 等阅读器仍在服务存量用户。
- 2022-2024 年：IndieWeb、Mastodon、长毛象中文圈为独立博主提供新的分发渠道；AI 摘要与搜索引擎流量下降成为新的流量焦虑。

## 平台与独立博客的对照

- 平台：流量分发归平台，读者关注的是"号"不是"人"；平台规则变化（推荐算法调整、内容审核收紧）直接影响写作者可见性。
- 独立博客：域名与内容归写作者，读者靠 RSS、邮件订阅、书签回来；流量小但留存高。
- 多位长期博主自述：独立博客月访问量从平台的百分之一到千分之一不等，但评论质量与来信质量高得多。
- 平台关停史：BlogBus 2015 年停止服务、饭否多次关停、简书转型、Medium 中文区收缩——内容迁移成本落在写作者身上。

## 技术与工具线索

- 静态站点生成器成本：一台 5 美元/月的 VPS 或 GitHub Pages 免费托管，年成本远低于公众号的隐性成本（无所有权）。
- RSS 是去中心化分发的技术基础，W3C 2023 年把 RSS 2.0 规范正式收编为 W3C 社区规范。
- Webmention、IndieAuth 等 IndieWeb 协议尝试把"评论、转发"还给独立站点，采用者少。
- 评论系统演变：自建（WordPress 内置）→ 第三方（Disqus、多说 2017 年关停）→ 静态方案（giscus、utterances 基于仓库 issue）。

## 写作者访谈线索（多位博主公开自述）

- "写在平台上像给别人打工，写在博客上像给自己盖房子，房子小但门是我的。"
- "公众号让我放弃了外链，读者无法引用我，我也无法引用别人。"
- "博客最大的敌人不是流量，是我自己半年不更新。"
- "AI 搜索来了之后，我的文章被摘要了，点击没有了，但我不知道该向谁要这个署名。"

## 数据素材

- 中国互联网络信息中心（CNNIC）历年报告：博客类应用使用率在 2011 年前后达到峰值后持续下降，被社交媒体类应用取代。
- 中文独立博客列表（GitHub 项目）收录站点数：2018 年约 800 个，2023 年约 3000 个，收录标准为独立域名 + 持续更新。
- 多位博主公开的后台数据：RSS 订阅量从 2013 年前的数千降到 2023 年的数百到千余，但退订率低。
