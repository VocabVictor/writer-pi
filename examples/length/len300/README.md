# len300 示例：短长度目标（300 字左右）

300 字档示例：电影短评，短档里最长的一档，验证接近长文阈值前的长度约束。

在这个目录启动 writer-pi：

```bash
cd examples/length/len300
writer-pi
```

然后在交互界面输入：

```
/draft 写一篇《冬泳》的短评
```

brief.md 写好口径（长度、语气、禁用词），sources/facts.md 是需要处理的事实。article.md 是一次真实运行得到的最终稿。

实测字数（口径：中文字符 + 英文单词 + 数字组）：243 字，目标 300 字（±20% 达标线 240–360，达标）。
