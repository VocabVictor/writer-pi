# مثال ar: مقال عن المدينة من مادة مصدرية

تشغيل writer-pi في هذا الدليل:

```bash
cd examples/ar
writer-pi
```

ثم الإدخال في الواجهة التفاعلية:

```
/draft اكتب مقالا قصيرا عن السوق القديم
```

يحتوي brief.md على المتطلبات (اللغة المستهدفة، النوع، الطول، الكلمات المحظورة)، ويحتوي sources/souq.md على المادة.
التوليد الحقيقي غير التفاعلي:

```bash
node ../../packages/coding-agent/dist/bundle/cli.js -a -p "/draft اكتب مقالا قصيرا عن السوق القديم" --no-session
```

تسير العملية تلقائيًا: مسودة، حفظ، فحوصات، مراجعات.
النص النهائي في article.md، والنسخ في drafts/.
