# len200 示例：短长度目标（200 字左右）

200 字档示例：交付延期的致歉短信，与 email 示例同量级，但重点在补救措施。

在这个目录启动 writer-pi：

```bash
cd examples/len200
writer-pi
```

然后在交互界面输入：

```
/draft 写一条交付延期的致歉短信
```

brief.md 写好口径（长度、语气、禁用词），sources/facts.md 是需要处理的事实。article.md 是一次真实运行得到的最终稿。

实测字数（口径：中文字符 + 英文单词 + 数字组）：163 字，目标 200 字（±20% 达标线 160–240，达标）。
